# Kali Mobile Pro

A modern Android application framework for network scanning, wireless analysis, web assessment, and reporting.

## Features
- Dashboard and tool overview
- Modular tool cards for networking, wireless analysis, and reporting
- Material 3 user interface
- Security-focused design and ready structure for future tool integrations

## Project structure
- `app/` — Android application source code
- `build.gradle.kts` — project Gradle configuration
- `settings.gradle.kts` — project settings
- `gradle.properties` — Gradle properties

## Run in Android Studio
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Select a connected device or emulator.
4. Run the app using the green Run button.

## Build from command line
```bash
gradle assembleDebug
```

## Notes
This repository contains a functional UI foundation for the Kali Mobile Android app and is ready for further expansion into scanning and exploitation modules.
