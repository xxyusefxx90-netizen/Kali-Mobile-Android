# Random Joke Generator

A simple web project that fetches random jokes from a public API.

## Files
- `index.html`
- `style.css`
- `script.js`

## Run locally
Open `index.html` in your browser, or use a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## API used
- https://v2.jokeapi.dev/
